# Level 1 mock exam

**Level:** Foundations · **Module 11:** Exam readiness 1 · **Page 4 of 4**
**Exams:** all (the questions follow the Associate blueprint, AS1 to AS7, over the content of modules 1 to 11)

**After this page you can** tell whether you are ready for the Associate exam, and which domains of Level 1 need more
work before you sit it.

This mock exam covers **the whole of Level 1** (modules 1 to 11) and not one page or one module. It is written in the
exam's style: a short scenario, one best answer and three plausible alternatives, each of which is a mistake a practitioner
could make. Every question is the course's own, written fresh; no question comes from a live exam. The facts behind each
answer were read on 2026-10-02 from the official pages named on the module pages, so a reader who studies
the pages can answer each question from them.

## How to take it

1. **Choose your conditions.** For a readiness test, take all 30 questions in **60 minutes** with no notes, which is the
   Associate exam's pace of two minutes a question. For learning, take it untimed and read each explanation.
2. **Answer every question.** The guides describe no penalty for a wrong answer.
3. **Mark each answer** and open the folded key at the end only when you finish.
4. **Score by domain,** not only in total, using the table below, and spend your next study session on the weakest domain
   with the most weight.

There is no official conversion from a mock percentage to a result: **the real pass mark is a scaled score of 720 on a
scale from 100 to 1,000**, so treat the mock as a guide to where you stand in each domain and never as a prediction.

## Mock exam

This mock exam covers the whole of Level 1, modules 1 to 11. Choose one answer for each question.

1. A user pastes a 25-page report beneath a one-line question and gets weak, unfocused answers. Which change is most likely
   to help?
   - **a**: Add a role such as world-class analyst to sharpen the focus
   - **b**: Shorten the question to a single word so that it stands out
   - **c**: Ask Claude to read the pasted pages twice before replying
   - **d**: Put the long material at the top, and the ask at the very end

2. A prompt supplies four policy documents, and the answers never say which document backs each claim, so reviewers cannot
   trace them. Which change fits best?
   - **a**: Merge the four into one paragraph so that they read smoothly
   - **b**: Wrap each in a numbered tagged block and ask for the number cited
   - **c**: Tell Claude to cite its sources more carefully in general
   - **d**: Rename the tags with something creative for each policy

3. A team needs replies in a rarely seen house format of three labelled lines, and instructions alone give inconsistent
   layouts. Which prompting style fits best?
   - **a**: Multi-shot, with a few varied samples of the wanted shape
   - **b**: Zero-shot, with a longer written description of the format
   - **c**: One-shot, with a sample taken from an unrelated task
   - **d**: No samples, with a role line promising to follow the layout

4. A manager types "Write something about our Q3 results" and receives a generic paragraph with no figures. Which revision
   best fixes the request?
   - **a**: Name the readers, the form, the numbers, and how to handle gaps
   - **b**: Ask for a longer piece, since more words will carry more detail
   - **c**: Add a reassuring role such as senior analyst, and keep the rest as it is
   - **d**: Run it several times and pick whichever result sounds best

5. A knowledge-base assistant answers every question, even when the manuals say nothing, and sometimes invents a procedure.
   Which prompt addition best tackles this?
   - **a**: Add the manuals to every request, even when they are unrelated
   - **b**: Raise the temperature so that it explores more possible answers
   - **c**: Allow it to admit that the supplied material does not address the matter
   - **d**: Ask for a confidence percentage beside each answer it gives

6. A test asserts that a Claude reply matches a stored string exactly. It passes today and fails tomorrow for the same input.
   What is the best interpretation?
   - **a**: The vendor swapped the model silently, so the id must be pinned and re-recorded
   - **b**: Replies can vary even at fixed settings, so judge quality across many cases
   - **c**: The prompt is faulty, and a line such as be consistent will stabilise it
   - **d**: The machine's clock changed the output, so the time must be frozen

7. A clinic administrator plans to have Claude read radiology scans uploaded by patients and report findings to them directly.
   Which concern matters most?
   - **a**: Names of the people in the images would be read out and shared automatically
   - **b**: Claude cannot read any image, so every scan would have to be described in words first
   - **c**: The scans are fine for the purpose, provided that they are sharp and in colour
   - **d**: These images lie outside the design, and a qualified reviewer must vet outputs

8. A communications assistant drafts a press note with Claude. It contains a quotation attributed to the chief executive and
   three statistics, and time is short. What should be checked first?
   - **a**: Spelling and tone, since those errors are the most visible
   - **b**: The CEO's remark and the figures, against the originals
   - **c**: Whether Claude says it is confident about each claim
   - **d**: Whether a second Claude draft contains the same claims

9. An analyst needs Claude's output to load into a database through a script, and also to show executives a short takeaway.
   Which pair of formats fits?
   - **a**: A published artifact with shared storage serving both audiences
   - **b**: An artifact for the ingest step, and a table in a slide deck for leadership
   - **c**: Inline replies for both, since artifacts only suit code
   - **d**: Machine-readable results for the ingest step, a brief inline note for leadership

10. A long Claude summary says in its first paragraph that revenue grew eight percent, and in its fifth that revenue declined
    slightly. What is the best step?
    - **a**: Check both statements against the source, then correct the draft
    - **b**: Keep the paragraph that appears first, since earlier text is more reliable
    - **c**: Ask Claude to reconcile the two and trust its reconciled text
    - **d**: Average the two figures to estimate the true growth

11. A retailer will draft about 5,000 short order-status replies an hour. Speed and cost matter most, and the replies are
    routine. What is the best starting point?
    - **a**: Use the middle tier until the invoices arrive, then decide
    - **b**: Use the most capable tier for every reply to protect quality
    - **c**: Begin with the fast, inexpensive tier and test it on past cases
    - **d**: Pick whichever tier the most experienced colleague prefers

12. A long chat in the app starts contradicting earlier decisions after many hours, though no error appears. What is the
    best action?
    - **a**: Instruct Claude to delete the older turns from its memory
    - **b**: Keep going, since a larger window guarantees consistent recall
    - **c**: Begin anew with a short recap of what was agreed
    - **d**: Upgrade to a model with a bigger window and carry on regardless

13. A strategist must compare twelve vendors using public sources and wants cited findings by tomorrow, with several rounds
    of investigation expected. Which feature fits best?
    - **a**: Research mode, with the web lookup setting enabled
    - **b**: A Project holding the vendors' brochures and no web access
    - **c**: A plain chat reply, since citations arrive with every answer
    - **d**: An artifact that renders the comparison as a dashboard first

14. A user tells Claude about her project in an incognito chat and finds that the next chat has no trace of it. Is this a fault?
    - **a**: No: she should have used a Project, since Projects always remember everything
    - **b**: Yes: the weights should have updated after the conversation
    - **c**: Yes: memory failed because the conversation was too short
    - **d**: No: such conversations are kept out of memory and history by design

15. A COO asks which of four chores suit Claude with review: (1) drafting vendor-email variants, (2) deciding which supplier
    to drop, (3) summarising call transcripts, (4) calculating invoice totals. Which pair is right?
    - **a**: The second and fourth
    - **b**: The first and third
    - **c**: The third and fourth
    - **d**: The first and second

16. A department head asks how Claude will change the team's work. Which message is the most balanced?
    - **a**: It cannot be trusted at all, so every use must be forbidden until further notice
    - **b**: It will do the job on its own, so we can cut the review time right away
    - **c**: It speeds drafts and summaries, people still check claims, results get measured
    - **d**: It is just a faster search engine, so nothing about anyone's role will change

17. An FP&A analyst must trace how a revenue figure in a long workbook is derived before presenting it. Which capability of the
    Excel add-in helps most directly?
    - **a**: Reading closed workbooks stored in the shared drive
    - **b**: Automatic sign-off of the figure by the add-in once it is asked
    - **c**: Macro execution that recalculates the whole workbook automatically
    - **d**: Answers about the open file that carry cell-level citations

18. A grants officer has Claude draft a funder report saying the programme transformed the community, with percentages taken
    from last year's file. Which review matters most?
    - **a**: Polish the wording so that the funder finds it persuasive
    - **b**: Tie each stated outcome and ratio back to the organisation's own data
    - **c**: Ask Claude to estimate how likely each percentage is to be correct
    - **d**: Remove all percentages so that no figure can be wrong

19. An online shop wants every order with a postcode outside its delivery zones flagged automatically, and 12,000 orders arrive
    daily. Which design is best?
    - **a**: A short program applies the geographic rule; Claude drafts customer notes
    - **b**: Claude reads each order and decides whether the postcode lies out of zone
    - **c**: Claude checks a sample of orders and the rest are assumed to be fine
    - **d**: Claude flags suspicious postcodes by feel, then code confirms them

20. A coordinator builds a small published artifact where visitors enter their dietary needs, and it keeps data. What should she
    check before inviting people?
    - **a**: Whether its storage is personal or visible to every user
    - **b**: Whether the artifact runs past fifteen lines, which decides its storage
    - **c**: Whether each visitor has the creator's plan, as usage bills to it
    - **d**: Whether visitors have connected the creator's own apps

21. A Project's HR assistant quotes a leave policy that was replaced, and both the old and the new document sit in its knowledge.
    What is the best fix?
    - **a**: Ask Claude to merge both files into a third file
    - **b**: Add an instruction to prefer the newer document whenever they conflict
    - **c**: Delete the superseded file and keep a copy in your own storage
    - **d**: Switch on memory so that Claude learns which policy is current

22. A team lead wants to share a Project that holds salary bands with the whole organisation. Which approach is right?
    - **a**: Rely on the instructions to keep the salary files hidden from the viewers
    - **b**: Grant it only to people entitled to the knowledge, since viewing shows everything
    - **c**: Share it widely, because can-view access stops viewers from reading the knowledge
    - **d**: Share it with everyone first and delete the files later if that proves necessary

23. A team wants every Claude Tag reply in one Slack channel to be brief and to link its source. How should the lead set this up?
    - **a**: Edit the model's settings so that its temperature drops to a lower value
    - **b**: Ask each member to type the rule again in every single thread they open
    - **c**: Set it in a Project, because Slack reads the Project's own instructions first
    - **d**: Tell the assistant so right there, where it is saved as standing instructions

24. A researcher wants Claude to analyse survey responses that include names and a free-text notes column. Which preparation is best?
    - **a**: Delete only the name column, since notes cannot identify anyone
    - **b**: Aggregate or generalise, and scan open-ended comments for stray details
    - **c**: Replace names with codes and keep the key file beside the data
    - **d**: Upload everything and ask for a summary that omits personal details

25. A professional asks Claude in Chrome to shortlist conference venues while her banking site is open in another tab. Which habit
    best limits harm?
    - **a**: Trust the classifier, since the risk of an attack is nil
    - **b**: Leave the bank tab open but tell Claude to ignore it
    - **c**: Switch on Skip all approvals so that no prompt interrupts the task
    - **d**: Use a clean profile, and approve each action manually

26. A consultant on a Pro plan asks whether her chats may be used to improve Claude. What is the accurate answer?
    - **a**: Only if she has allowed it in her settings, and incognito sessions are excluded
    - **b**: Always, since consumer plans train on every single conversation they hold
    - **c**: Never, under any circumstance, even when she presses the feedback buttons
    - **d**: Only for the first thirty days after each conversation has taken place

27. A manager lets Cowork reach her entire documents drive to save time, and it holds tax returns and exported passwords. What
    should change?
    - **a**: Keep the access and rely on the cloud sandbox to protect everything
    - **b**: Keep the access but switch to automatic approval for speed
    - **c**: Connect a dedicated folder containing only the task's files
    - **d**: Keep the access, but ask Claude to ignore the sensitive files

28. A model gives correct, well-formatted answers on a labelling task but is too slow for a live chat widget, and the instructions
    and context are good. Which step fits?
    - **a**: Reword it with a stronger role such as expert labeller
    - **b**: Add more context to the prompt, since slowness comes from missing detail
    - **c**: Evaluate a faster tier or lower effort against the same test set
    - **d**: Add a retrieval step to supply today's data

29. A nightly job re-scores 200,000 archived documents, and the results are due the next morning. Which cost lever fits best?
    - **a**: Batched requests, which are half the price of standard ones
    - **b**: Prompt cache reads, which price every output token lower
    - **c**: Fast mode, which doubles the output speed at premium pricing
    - **d**: Higher effort, which trades latency for cost

30. After a mock, a candidate notices that most misses were options that asked Claude to confirm its own answer. What is the best
    next step?
    - **a**: Retake the mock at once, without reading the pages behind the misses
    - **b**: Memorise the answer letters for each such question in the bank
    - **c**: Ignore them, as the domain results do not decide the pass
    - **d**: Study that distractor family, and why claims go to the source

2. **b**. 3. **a**. A rare format with subtle boundaries calls for several varied examples (module 6, page 2). *b* is ruled out because zero-shot suits a case where "The task is common and easy to describe", and this format is not. *c* is ruled out because examples should "Mirror your actual use case closely", and an unrelated sample does not. *d* is ruled out because "A role is a request, not a credential", so a role line does not fix a layout.
4. **a**. 5. **c**.
